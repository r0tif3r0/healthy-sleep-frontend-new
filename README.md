# Здоровый сон — фронтенд

Веб-приложение дистанционного мониторинга СИПАП-терапии: пациент загружает данные с карты памяти прибора, врач видит динамику показателей.

## Запуск

```bash
npm ci
cp .env.example .env.local   # и поправьте адреса
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на 5173 |
| `npm run dev:demo` | То же, но с демо-данными вместо бэкенда |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run build:demo` | Сборка демоверсии для показа заказчику |
| `npm run lint` | ESLint |
| `npm test` | Тесты (Vitest) |

## Демо для показа

Есть режим, в котором приложение работает без бэкенда: запросы перехватывает service worker и отвечает подготовленными данными. Нужен для показа. Как запустить, как выложить и как потом удалить одной командой — в [src/demo/README.md](src/demo/README.md).

## Стек

React 18, Vite 5, TypeScript strict, Tailwind CSS 4 (токены в `@theme`), TanStack Query 5, axios, react-router-dom 6, react-hook-form + zod, Chart.js 4, react-day-picker 9, date-fns 4, JSZip. Тесты — Vitest + Testing Library + MSW.

Компоненты собственные: готовый UI-кит и был причиной прежнего «шаблонного» вида.

## Структура

```
src/
├── app/          провайдеры (запросы, тема, авторизация), маршруты и охрана
├── pages/        по файлу на маршрут, только композиция
├── widgets/      оболочка приложения, графики, виджеты показателей, печатный отчёт
├── features/     авторизация, статистика, загрузка, профиль, пациенты
├── shared/       api, ui, icons, lib, config, hooks
├── assets/       иллюстрации и шрифты
└── styles/       токены, базовые стили, печатная форма отчёта
```

Расчёты и форматирование вынесены в `shared/lib/metrics.ts` и `shared/lib/format.ts` и покрыты тестами: раньше те же формулы жили внутри разметки, и приверженность из карточки не сходилась с приверженностью из отчёта.

## Единицы измерения

Задаются в `shared/lib/format.ts` и больше нигде:

| Показатель | Единица |
|---|---|
| Давление, минимальное и максимальное давление, EPR | `мм рт. ст.` |
| AHI, AI, OAI, CAI, HI, UAI | `событий/час` |
| Плавный старт (Ramp) | `мин` |
| Утечки | `л/мин` |
| Длительность | часы и минуты |
| Приверженность | `%` |

Давление подписано в **мм рт. ст.** по решению заказчика: так оно приводится в заключениях центра. Находка Н-14 снята, менять подпись не нужно.

## Отчёт для врача

Собирается из данных и печатается средствами браузера (кнопка «Выгрузить отчёт» → печать → «Сохранить как PDF»). Разметка отчёта — `widgets/report/PatientReport.tsx`, печатные стили — `styles/report.css`.

## Закрытые находки из реестра

Н-5 (адрес из окружения, показываемая и копируемая ссылка совпадают), Н-9 (выгрузка недоступна, когда нечего выгружать), Н-12 (дата рождения в будущем отклоняется), Н-15 (индексы в событиях в час), Н-16 (плавный старт в минутах), Н-17 (`EPR`), Н-18, Н-19, Н-20, Н-38 (отчёт из данных, многостраничный, с русскими подписями), Н-25 (видно, сколько ночей добавлено), Н-28 (календарь открывается на последнем месяце с данными), Н-34 (приверженность объяснена), Н-35 (нет лишнего пробела в ФИО), Н-37 (список пациентов на узком экране), Н-40 (появились тесты), Н-42 (нет отладочного вывода).

Остаются за бэкендом или за заказчиком: Н-1, Н-2, Н-3, Н-4, Н-6, Н-7, Н-8, Н-10, Н-11, Н-21…Н-27, Н-29…Н-33, Н-36, Н-39, Н-41, Н-43, Н-44.

## Что ждёт текста

В интерфейсе стоят видимые скобки — их нельзя выдумывать:
